# OSS ChatGPT 학습 구성

별도 API 키 없이 사용할 수 있습니다. OSS 웹의 ‘GPT로 실행’은 자료 복사와 ChatGPT 열기 안내를 보여 줍니다. 실제 AI 처리는 ChatGPT 대화 안에서 이루어집니다. Claude 아티팩트와 같은 웹 화면이 ChatGPT 안에서 자동 실행되는 기능은 구현하지 않습니다.

## 바로 사용

1. OSS에서 ‘GPT로 실행’을 선택합니다.
2. 프로필·최근 기록을 확인한 후 ‘학습 자료 복사’ → ‘ChatGPT에서 열기’를 선택하고 붙여넣습니다.
3. 기록 저장이 필요한 학습은 웹에서 평가·스크립트·해석·모의시험·분석 버튼으로 요청을 만듭니다. ‘요청 복사’ → ChatGPT에 붙여넣기 → 결과 코드 블록을 웹에 붙여넣기 순서입니다.
4. 대화는 웹에서 상대를 선택한 후 ChatGPT 안에서 이어갑니다. ‘뭐라고 말하지?’는 힌트, ‘해석’은 번역, ‘종료’ 또는 ‘웹으로 통합’은 요약 결과를 반환합니다.

## 전용 GPT 구성 (선택)

사용 중인 ChatGPT 계정에 전용 GPT 만들기 기능이 있으면:

- 이름: **OSS OPIc Study**
- 설명: **기존 OSS 프로필·질문은행으로 OPIc 평가, 스크립트, 듣기 예문, 모의시험, 대화와 번역을 연습하고 결과를 웹 기록에 가져옵니다.**
- Instructions: `INSTRUCTIONS.md` 내용 전체
- Knowledge: `study-reference.json` 첨부
- Actions/API 인증: 설정하지 않음
- 대화 시작 문구: ‘오늘 30분 학습을 시작할게요’, ‘이 답변을 IM3 기준으로 평가해 주세요’, ‘오픽 인터뷰어와 대화할게요’, ‘15문항 모의시험을 시작할게요’

우선 비공개로 저장하고 웹 요청으로 평가·스크립트·대화 종료 결과를 확인합니다. 본인에게 접근 가능한 GPT 링크를 복사한 뒤 OSS 설정의 ‘ChatGPT 학습 링크’에 저장하세요. 지원하지 않는 계정은 기본 ChatGPT 대화에 요청을 붙여넣는 흐름으로 사용할 수 있습니다. GPT를 실제 계정에 생성하거나 게시한 것은 아닙니다.

독립 학습도 가능하지만 웹 저장에는 웹에서 만들어 둔 요청 ID가 필요합니다. ChatGPT가 요청 ID를 임의로 만들거나 Firebase에 직접 저장했다고 주장하면 그 결과를 사용하지 말고, 웹 요청을 다시 붙여넣어 지정한 결과 형식으로 출력하도록 요청하세요.

## 유지보수

질문은행을 바꾼 뒤 `node tools/build-chatgpt.cjs`와 `python tools/build.py`를 순서대로 실행합니다. 전자는 기존 앱의 주제·롤플레이·고난도·대화 시나리오·평가 기준을 JSON으로 내보내고, 후자는 ChatGPT 자료를 Pages의 `docs/chatgpt/`에도 복사합니다.
